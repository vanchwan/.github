# Vanchwan | 万川开源社区
> Streams of wisdom converge

Vanchwan（万川）是面向AI时代的开源组织，汇聚全球开发者共建大模型、智能体、算力工具链。
百川汇海，众智共生。我们致力于打造开放、普惠的AI基础设施与智能体生态。

## 🎯 组织愿景
聚集多源智慧，构建可自由组合、可扩展的开源AI组件生态，降低通用智能的开发门槛。

## 📦 项目方向
- Agent / 多智能体框架
- LLM推理、模型工具链
- RAG、知识图谱相关工具
- AI开发组件、MCP工具集
